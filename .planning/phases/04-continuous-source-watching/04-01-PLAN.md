# Plan 04-01: `[[watch]]` config surface (parse, resolve, secrecy)

## Objective
As an operator, I want to declare a WebDAV folder as a watched source in `config.toml` so the daemon knows what to poll — with sane defaults, hard validation, and a password that can never leak through logs or Debug output. This is the config half of the phase's first vertical slice (pure logic; the poller consumes it in 04-04).

## Context
- Integration point: `crates/saussunet-core/src/config.rs` — `FileConfig` (line 12) gains `#[serde(default)] pub watch: Vec<WatchSection>`; `RuntimeConfig` (line 230) gains `pub watch: Vec<ResolvedWatch>`. The `SecretString` pattern (line 59, Debug renders `***`) is reused verbatim for `password`.
- WR-02 precedent: zero-value numerics are rejected at `resolve()` (see `zero_max_concurrency_is_rejected`), never at first use.
- **Hard coupling:** `default_config()` in `lib.rs:134` is byte-identical-tested against root `config.example.toml` (`committed_example_config_matches_default_config`, lib.rs:192). BOTH files are updated in THIS plan, same commit.
- D-03: watch URLs may point at private/LAN IPs — do NOT call `pipeline::fetch::assert_public_http_url` here. The only URL rules: parses as `url::Url`, scheme http/https, no userinfo.
- Concrete shape (exact names — downstream plans use them):
  ```rust
  pub struct WatchSection {
      pub url: String,
      #[serde(default)] pub username: Option<String>,
      #[serde(default)] pub password: Option<SecretString>,
      #[serde(default = "default_watch_interval_secs")] pub interval_secs: u64,   // 300
      #[serde(default = "default_watch_depth_cap")] pub depth_cap: u32,           // 4
      #[serde(default = "default_watch_extensions")] pub extensions: Vec<String>, // ["md","txt","pdf"]
  }
  pub struct ResolvedWatch {
      pub source_id: String,               // url verbatim (state key — stable across restarts)
      pub url: url::Url,
      pub username: Option<String>,
      pub password: Option<SecretString>,  // Debug-safe
      pub interval: std::time::Duration,   // tests construct 10 ms directly
      pub depth_cap: u32,
      pub extensions: Vec<String>,         // lowercased, dot-stripped
  }
  ```

<threat_model>
- **Credential leakage (D-02):** password is `SecretString` only; `watch_password_never_in_debug` proves absence from `{:?}` of FileConfig, the section, and RuntimeConfig. URLs containing userinfo (`https://u:p@host`) are REJECTED at resolve — creds in URLs leak via reqwest error Display in later plans.
- **Config DoS (WR-02 parity):** `interval_secs = 0` / `depth_cap = 0` rejected at resolve (0 would hot-loop / walk nothing).
- **SSRF:** N/A by decision D-03 — watch URLs are operator-trusted; enforced absence of the public-IP guard is itself the documented behavior. Prompt injection / untrusted-response threats land in 04-03/04-04 (parser + client).
</threat_model>
