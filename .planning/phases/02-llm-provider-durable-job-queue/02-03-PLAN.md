<threat_model level="OWASP-ASVS-L1" block="high">
- **Prompt injection via payload (HIGH):** generate_json receives prompt text that downstream (Phase 3) builds from untrusted source content. Mitigation contract: provider implementations treat the prompt strictly as message content — no shell/eval, no URL fetching from prompt text; repair prompt embeds the model's own prior output truncated to 4000 chars (bounded echo, prevents token-bomb amplification). Output is only ever serde_json-parsed into typed T — never executed, never interpolated into SQL (store layer binds params).
- **Unbounded resource use:** MockProvider Hang variant is test-only; script Vec is finite and script-exhaustion is a hard error, not a hang.
- **Secret leakage:** no secrets exist in this slice (mock only); trait signatures must not carry api_key (it stays inside provider impls, D-03).
</threat_model>
