# 04.1-05: migrate-okf — in-place llm-wiki → OKF conversion with refusals and parity

## What was built

**`crates/saussunet-core/src/migrate.rs`** (new, ~1000 lines) — the embeddable converter (D-28):

- `walk(root)` — recursive `.md` walk honoring `SKIP_DIRS` {.git, scripts, assets, __pycache__, node_modules}, skipping and reporting symlinks (never following), canonicalizing root once and re-checking containment per file.
- `parse_lenient` — dirty frontmatter never aborts the migration; a page that fails to parse is reported and left alone.
- `convert_file` dispatch: root `index.md` → D-17/D-18 rebuild (quoted `okf_version: "0.2"`, description backfill with `[[…]]`/`^[…]` sanitizing); root `log.md` → `reformat_log` to the 04.1-02 bullet shape (date-grouped, newest-first); `SCHEMA.md`/`AGENTS.md`/`README.md` → meta types; `raw/**` → Source frontmatter (resource/timestamp from ingested/sha256); page dirs → full v0.2 frontmatter via the 04.1-01 funnel pieces (type fold, generated block, sources union, wikilink rewrite via `okf::build_slug_map`/`rewrite_wikilinks`, footnote rewrite via `rewrite_citations`).
- Protected pages (`protected: true`) skipped and reported (D-26).
- `dry_run` — full conversion computed in memory, nothing written (D-23).
- `convert_tree` — mutation core: single `vault.write_lock` pass through `atomic::write_atomic` only, two-pass gen_hash re-seed over final bytes (Pitfall 2/D-26), `log::append_entry("migrate-okf", …)`, then `reindex` so SQLite matches the tree (D-27).
- `apply` — refusal gates (below) + optional backup archive + `convert_tree`.
- `already_converted` — root index frontmatter `okf_version` OR ≥80% of non-reserved pages carry `generated:` (MoriNet threshold shape).
- `decide_undo` (pure) + thin git probes: git missing → `CoreError::MissingBinary` with install hint; repo dirty → refuse; non-git without `--backup` → refuse (D-25).
- `create_backup` — `tar -czf <dir>/vault-<stamp>.tar.gz` of the tree BEFORE any mutation; failure aborts loudly.
- `verify` — read-only `okf::check_bundle` + `count_broken_links`; Clean iff zero errors (D-24).
- `MigrateReport` (Serialize) + human/JSON renderers; verdict `Clean | Refused { reason }`; relative paths and counts only.

**`okf::check_bundle(root)`** (okf.rs) — full okflint `check_bundle` port: every `.md` under root honoring SKIP_DIRS, symlinks skipped, reserved rules (E3 frontmatter-forbidden / W0 / E4 log) on root AND nested `index.md`/`log.md` basenames, `check_page` on the rest, broken bundle-relative links counted as INFO (never errors).

**CLI** (`crates/saussunet/src/main.rs`) — `saussunet migrate-okf --vault <name> [--apply] [--verify] [--json] [--backup <dir>]`; same boot wiring as other commands, unknown vault name is a loud exit 1, refusal/conformance-error exit 1, `--json` uses `serde_json::to_string_pretty` (conflicts_cmd precedent).

## Deviations from plan

1. **`convert_tree` split out of `apply`** — T13 drives conversion on the already-OKF-looking B3Wiki tree, which `apply` would refuse via `already_converted`; the plan's "run the same conversion" needs a gate-free embeddable entry. `apply` = gates + backup + `convert_tree`.
2. **Nested `index.md`/`log.md` treated as reserved** (Unchanged, no frontmatter) — discovered by T13: B3Wiki's section catalogs (`entities/albums/index.md` etc.) are frontmatter-less and okflint flags any frontmatter on them (E3). `build_tree` also excludes them from page/slug maps.
3. **Existing `sources[]` map entries preserved verbatim** — B3Wiki pages carry https-URL source maps; rebuilding from `source_paths()` alone would mangle them into `/https://…` resources. Flat strings and `^[…]` markers are deduped against preserved resources.
4. **T12 threshold fixture drops the seeded `SCHEMA.md`** — it joins the non-reserved denominator (MoriNet shape) and would shift the 4/5 vs 3/5 boundary; the test removes it to count exactly its 5 pages.
5. **Zero-write snapshot excludes `.git/`** — `git status --porcelain` refreshes `.git/index`'s stat cache; the zero-write claim is about vault files.
6. **T11 `source_url` assertion relaxed** — serde_yml quotes URL scalars; asserts key+value presence instead of exact `key: value` line.
7. **T11 protected fixture is already vocabulary-conformant** (`type: Concept`) — protected pages are skipped by design (D-26), so a non-conformant protected page would keep the bundle verdict failing.

## Decisions

- Refusal verdicts are data (`Verdict::Refused { reason }`), not errors — the CLI maps them to exit 1; hosts can branch on them.
- `--backup` archive only produced when the vault is not a git repo; a clean worktree is its own undo path (D-25 intent, avoids redundant multi-MB archives).
- `check_bundle` returns `Vec<String>` (rule-prefixed messages) rather than a Violation struct — matches how every caller renders it and keeps okf.rs free of new public types.
- `verify` counts broken links as INFO (D-21 §5.3 tolerance) — verdict depends on errors only.

## Lessons

- okflint's reserved-file rule is **basename-based**, not root-based: any nested `index.md`/`log.md` must stay frontmatter-less. A converter that dispatches on "is this a page dir" alone will violate it.
- `git status` is not read-only — it can rewrite `.git/index` (stat-cache refresh), so zero-write snapshots around git probes must exclude `.git`.
- MoriNet's already-converted threshold counts every non-root-index/log `.md` in the denominator — seeded meta files (SCHEMA.md) dilute it; fixtures must account for it.
- serde_yml: `Mapping::get("key")` works with `&str`; `to_string()` on a `Value` omits the trailing newline; URL scalars come back quoted — assert loosely on serialized YAML.
- The patch tool mangles literal `^[` in replacement strings; use `execute_code` string replacement for content containing caret+bracket sequences.
