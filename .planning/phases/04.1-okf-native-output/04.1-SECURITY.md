## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| LLM → vault writer | Model-generated page content (title, description, page_type, body links/citations) enters the write funnel `writer.rs::write_generated_page` | Untrusted text → vault files (frontmatter, index.md, log.md) |
| External sources → vault | Ingested URL/PDF/WebDAV content becomes raw records and drives generated pages | Untrusted content → vault files |
| Vault filesystem → migrate-okf | `migrate-okf` walks and rewrites an existing vault tree in place | Arbitrary on-disk files (incl. symlinks, git state) → converted bundle |
| Write funnel → disk | Sole mutation path is `atomic::write_atomic` under the vault write lock (enforced by `scripts/check.sh` write-funnel grep) | Validated vault bytes → filesystem |
