# Phase 04.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.
> Derived from `04.1-RESEARCH.md` § Validation Architecture (T1–T13, mapped 1:1
> to the 5 ROADMAP success criteria).

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | cargo test (Rust, MockProvider only — zero real LLM in CI) |
| **Config file** | none — workspace `Cargo.toml` + `scripts/check.sh` gates |
| **Quick run command** | `cargo test --lib <module>::<test> 2>&1 \| tail -5` (targeted) |
| **Full suite command** | `scripts/check.sh` (fmt, clippy -D warnings, `env -u SAUSSUNET_LLM__API_KEY cargo test`, axum-absence + write-funnel greps, release build) |
| **Estimated runtime** | ~30 s targeted · ~3–5 min full gate |

---

## Sampling Rate

- **After every task commit:** Run the targeted test for the touched module (`cargo test --lib <module>::`)
- **After every plan wave:** Run `scripts/check.sh` (redirect to a file, check `$?` — do not pipe-mask the exit code)
- **Before verify-work:** Full suite must be green
- **Max feedback latency:** ~300 seconds
