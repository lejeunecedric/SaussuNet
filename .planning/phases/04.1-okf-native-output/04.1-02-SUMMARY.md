## Decisions

- `link_whitelist` keeps `HashSet<String>` return (stem semantics); the stem→path map lives in the new `validate::index_entry_map` so 04.1-03's resolver consumes paths without breaking the 4 existing callers.
- Index entry path derived as `/{section.to_lowercase()}/{stem}.md` — the four llm-wiki sections map 1:1 to the four page directories (writer already passes `index_section(rel_path)`), so no extra parameter was needed.
- Action strings kept verbatim from the old headers (`refuse`, `conflict`, `update`, `create`, `drift`) per plan; old `refused` normalized to `refuse` per the plan's action list.
- Date-heading shape implemented ONCE (`okf::log_date_ok`), reused by `log::is_date_heading` and `okf::check_log` — D-21 "one implementation of conformance" extended to the shape predicate.
- `append_entry` sanitizes subject AND details internally, so call sites pass raw values (writer/watch/pipeline no longer pre-sanitize).
- Log seed entry renders as `* **create**: Wiki initialized` with `  - Domain:` sub-bullets — same information, new shape (T7 pins it).

## Lessons

- A format flip's blast radius is bigger than the plan's grep list: `## [` log pins were enumerated, but index `[[stem]]` pins and `action |` substring pins in tests only surfaced in the full suite. Before a format change, grep tests for ALL substrings of the old format (`[[stem]]`, `create |`, ` | `), not just the heading prefix.
- Splitting a multi-feature RED test file per task (stash the Task-2 tests, restore at Task-2 RED) keeps each GREEN commit compilable — a single RED file referencing both unimplemented signatures makes Task 1's GREEN impossible.
- `cargo test` without `--no-fail-fast` stops at the first failing target and the aggregated `test result` sum then silently under-counts; use `--no-fail-fast` for the final tally.
- check.sh's clippy gate catches `format!` without args (`useless_format`) that plain `cargo test` never sees — run check.sh before declaring GREEN, not after.
- SQLITE_BUSY flakes in sqlite-backed tests reproduce on parent commits too — bisect against the parent worktree before claiming a regression.
