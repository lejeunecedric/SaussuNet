## Fixes

- **H1** — `vault/log.rs` `append_entry` `Some(p)` branch: extend with
  `lines[header_end..=p]` instead of `lines[..=p]` (`out` already holds
  `lines[..header_end]`, so the old slice re-emitted the header block on
  every append into an existing date group).
- **H2** — `migrate.rs` `convert_meta`: when converting `SCHEMA.md`
  (`want == "Schema"`) and the body has no `## Entity Subtypes` section,
  append the section with the default vocabulary
  (`Person, Organization, Tool, Place, Event, Work`, same wording as the
  SCHEMA seed). The `Unchanged` early-return now also requires the body to
  be untouched, so an already-`Schema`-typed SCHEMA.md missing the section
  still gets repaired.
- **M1** — `vault/schema.rs`: subtype bullet parsing extracted into
  `entity_subtypes_from_text(content)` (silent-empty; `parse_entity_subtypes`
  keeps the fail-loud wrapper). `vault/okf.rs` `check_bundle` now builds
  `DEFAULT_TYPE_VOCAB ∪ entity_subtypes_from_text(root/SCHEMA.md)` — the same
  union the write path uses — and passes it to `check_page`. Signature
  unchanged, so `migrate::verify` and the Phase-5 lint inherit the fix.
- **M2** — `vault/writer.rs`: `fm.description` is passed through
  `sanitize_for_nav` at the `upsert_entry` call (same posture as the title
  and the log subject), collapsing newlines so a description can no longer
  forge a `- [Title](/path.md)` index entry feeding the link whitelist.
